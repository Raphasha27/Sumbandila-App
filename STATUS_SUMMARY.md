## 💡 DEVELOPER NOTES

### To Start Development:
```bash
# Web App
cd apps/web
npm install
npm run dev

# Mobile App
cd apps/mobile
npm install
npm start

# Python Service
cd services/auth
pip install -r requirements.txt
uvicorn main:app --reload
```

### To Deploy:
```bash
# Web - Automatic on push to main
git push origin main

# Mobile - Using EAS
cd apps/mobile
eas build --platform android
```
