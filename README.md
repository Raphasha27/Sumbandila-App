## 🏛️ Enterprise Architecture
Sumbandila is engineered as a **Domain-Driven Monorepo**, utilizing modern microservices for extreme scale and observability.

### 🧩 Core Engines
- **Auth Service**: Federated Identity via OIDC standards.
- **Core Registry**: High-concurrency certificate management (FastAPI + Pydantic v2).
- **AI Sentinel**: Predictive Fraud Detection analyzing real-time Redis event streams.
- **Audit Pulse**: Transparent, immutable event logging (OpenTelemetry + Prometheus).

### 🛠️ Technology Stack
- **Frontend**: Next.js 15, Vite, Framer Motion, Zustand.
- **Mobile**: React Native, Expo 54, Lucide Icons.
- **Backend**: Python 3.12, FastAPI, Redis, PostgreSQL.
- **Infrastructure**: Docker, OpenTelemetry, Jaeger, Grafana.
